# References

These are official or established learning resources related to the workshop. They are additional learning references, not replacements for the workshop exercises.

- [Git documentation](https://git-scm.com/doc) — official reference documentation, installation information, and command manuals.
- [Pro Git](https://git-scm.com/book/en/v2) — the free book covering Git concepts, branching, remotes, and advanced usage.
- [GitHub Docs](https://docs.github.com/en) — current GitHub guidance for repositories, Issues, Pull Requests, authentication, and security.
- [GitHub Skills](https://skills.github.com/) — interactive GitHub learning exercises for repositories, Markdown, Pull Requests, and collaboration.
- [Oh My Git!](https://ohmygit.org/) — an interactive visual game for learning Git concepts and commands.

## How to use these references

- Use **Git documentation** when you need the exact behavior or options for a command.
- Use **Pro Git** when you want a fuller explanation of Git's underlying model.
- Use **GitHub Docs** for GitHub website features, authentication, and security settings.
- Use **GitHub Skills** for guided browser-based practice.
- Use **Oh My Git!** when a visual, interactive explanation would help.

When commands or security practices change, prefer the current official documentation over copied examples.
