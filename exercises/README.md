# Exercises

These exercises are designed to be completed in order. Use a temporary practice repository so that mistakes do not affect an important project.

| Exercise | Main practice |
| --- | --- |
| [Git fundamentals](git-fundamentals.md) | Configure Git, commit local work, connect to GitHub, clone, push, and pull. |
| [Branching and collaboration](branching-and-collaboration.md) | Create a feature branch, publish it, review work, merge, and resolve a conflict. |

## Before you begin

- Install Git and check it with `git --version`.
- Have a GitHub account available for the remote-repository steps.
- Choose an email address you are comfortable associating with your commits.
- Use a repository where you have permission to push.
- Read the [authentication and security guide](../guides/authentication-and-security.md) before entering credentials.

Try each task before reading the hints. If something goes wrong, start with `git status` and use the [troubleshooting guide](../resources/troubleshooting.md).
