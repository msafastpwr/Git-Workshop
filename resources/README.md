# Resources

These pages are quick references to use while practicing. They support the workshop topics without replacing the explanations and exercises.

| Resource | Use it when you need to... |
| --- | --- |
| [Git cheatsheet](git-cheatsheet.md) | Look up a command, its syntax, and a short example. |
| [Git workflow](git-workflow.md) | Understand the working directory, staging area, local repository, and remote repository. |
| [Branching and merging](branching-and-merging.md) | Create feature branches, merge work, or resolve conflicts. |
| [Collaboration workflow](collaboration-workflow.md) | Follow a team process from Issue to Pull Request and merge. |
| [Troubleshooting](troubleshooting.md) | Recover from common mistakes and Git errors safely. |

The cheatsheet prioritizes commands used in the exercises. More advanced commands should be used only after understanding the effect on local and shared history.
